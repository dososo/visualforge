换成你的

单张、套图与宫格

三步开始

下载一个系统安装包包内同时包含本地连接组件和 Chrome 扩展。
安装连接并加载扩展运行安装入口，在 chrome://extensions 加载解压后的扩展目录。
检查 Codex 连接VisualForge 设置里看到“Codex 已连接”后即可创作，无需 API Key。
