VisualForge 是一个接入本机 Codex 的 **Chrome 侧边栏插件**。在网页上看到喜欢的照片、写真或商品广告时，直接捕获它；VisualForge 会理解构图、动作、光影、色彩、材质和氛围，再结合你的人物或商品素材，生成属于你的单张作品、成套写真或宫格图。

## VisualForge 是什么

它由两部分组成：

- **Chrome 侧边栏插件**：捕获参考图、查看画面理解、添加人物或商品、管理结果。
- **本地连接组件**：连接你已经登录的 Codex，调用视觉理解和图像生成能力；不需要另填 API Key。

VisualForge 不是滤镜，也不是让你从空白提示词开始。它的起点始终是一张你真正喜欢的视觉：**先理解为什么好看，再把画面里的主体换成你的。**

## 适合谁

- **内容创作者**：把收藏的视觉方向快速变成自己的封面、配图和系列内容。
- **摄影师与模特**：从一张灵感图建立可执行的写真方向、镜头组合和成套作品。
- **品牌、电商与独立卖家**：用现有商品照片尝试广告构图、材质表现和不同视觉气质。
- **设计师与创意团队**：把“我想要这种感觉”变成可查看、可修改、可复用的作品记录。
- **普通用户**：不学习复杂提示词，也能从喜欢的图片开始创作。

## 有什么用

传统做法要先描述风格、反复试提示词、整理人物或商品素材，再逐张对齐构图和氛围。VisualForge 把这些步骤收成一条清楚的路径：

> **找到喜欢的视觉 → 让系统理解画面 → 换成你的人物或商品 → 生成并选择最终作品。**

它的价值不是“一键随机出图”，而是减少沟通和试错，让参考图、主体素材、每次候选、质量建议和最终选择始终在同一个作品里。

## 核心能力

| 能力 | VisualForge 做什么 | 你得到什么 |
| --- | --- | --- |
| 网页与本地参考 | 网页图片直接捕获，也可上传或粘贴 | 灵感无需先下载、改名、再找回来 |
| 参考图理解 | 分析构图、景别、动作、表情、光线、色彩、材质和后期 | 看得懂的创作方法，不只是一段黑盒提示词 |
| 人物／商品替换 | 参考图负责视觉方法，你的素材负责身份、体型或商品结构 | 生成“你的版本”，避免参考人物污染主体 |
| 单张、套图与宫格 | 支持单张及 2／3／4／6／9／12 个画面，宫格在本地合成 | 一张主视觉、完整写真组或社交媒体宫格 |
| 逐张选择与修改 | 每张保留候选、质量建议、定向重做和 Final Selection | 不因一张有问题就整组从头生成 |
| 本地作品管理 | 保存作品、素材关系和生成记录 | 随时继续、回看和导出，不依赖 VisualForge 云端账号 |

## 人物与商品风格全景

VisualForge 不把“风格”理解成套在图片上的滤镜。当前内置风格系统共 **48 个原创风格、6 个类别**，从景别、视角、空间、光线、色彩、材质、动作和后期质感共同建立可执行的视觉规则。下面完整列出其中专门为人物与商品建立的 16 个风格；另外 32 个风格覆盖电影叙事、当代东方、艺术编辑和生活方式等跨域方向，也会按参考图与创作目标参与推荐。

风格只负责“画面应该如何成立”，不会覆盖你上传人物的身份、体型或商品结构，也不会替你决定最终作品。参考图的可观察事实仍是第一优先级；内置风格用于补全方法，而不是把所有作品改成同一种模板。

## 商品广告

把人物换成商品，同一条流程就能用于香水、美妆、食品包装、数码配件、服装、家居器物等广告视觉：

1. 选择一张喜欢的商品广告或商业摄影作为参考。
2. 添加自己的商品照片；多角度素材可以帮助理解轮廓、标签、材质和结构。
3. VisualForge 分开处理“参考广告怎么拍”和“你的商品是什么”，再生成单张主视觉或一套广告画面。
4. 逐张检查商品结构、文字、材质、倒影和比例，选定最终版本后导出。

适合前期视觉探索、提案、社交媒体素材和小批量内容制作。生成结果仍需你对品牌文字、商品结构和商业使用权做最终确认。

## 使用流程

1. **找到参考**：在网页图片上点击 VisualForge，或在侧边栏上传／粘贴图片。
2. **确认理解**：查看画面事实、创作方法和可复用提示词，必要时直接修改。
3. **决定是否替换**：选择“换成我的”添加人物或商品；不替换也可以继续。
4. **选择交付**：明确生成单张、拍一套，或按 2／3／4／6／9／12 宫格生成。
5. **逐张确认**：查看结果和质量建议；只有你明确点击时才会额外重做。
6. **选定与导出**：为每张选择 Final Selection，套图可再合成横向／纵向宫格并导出。

## 三步开始

第一次安装请按下面顺序做。更完整的逐系统说明见[《VisualForge 最小安装指南》](INSTALL.md)。

### 第 1 步：安装并登录 Codex，然后下载 VisualForge

1. 先确认本机 Codex 已安装、已登录，并且能正常打开使用。VisualForge 使用这份登录状态，不需要 API Key。
2. 打开 [VisualForge Releases](https://github.com/dososo/visualforge/releases/latest)，只下载与你系统对应的一个包：
   - macOS：`VisualForge-0.5.8-macos-universal.dmg`（Apple 芯片＋Intel）
   - Windows 10／11 x64：`VisualForge-0.5.8-windows-x64.zip`
   - Linux x64：`VisualForge-0.5.8-linux-x64.tar.gz`

### 第 2 步：安装本地连接组件，并加载 Chrome 扩展

1. 安装连接组件：macOS 双击 DMG 内的 `Install.command`；Windows 解压后右键 `Install.ps1` 并选择“使用 PowerShell 运行”；Linux 解压后运行 `./install.sh`。
2. 在安装包中找到 `VisualForge-extension.zip`，把它解压到一个以后不会移动的固定文件夹。
3. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择刚才解压出的扩展文件夹。到这里即完成 **加载 Chrome 扩展**。

### 第 3 步：确认连接，开始第一张作品

1. 点击 Chrome 工具栏中的 VisualForge，打开侧边栏。
2. 打开设置，点击“重新检查连接”；顶部显示 **“Codex 已连接”** 即安装成功。
3. 回到“创作”，上传或粘贴一张参考图；也可以打开普通 HTTPS 网页，在喜欢的图片上使用 VisualForge。
4. 查看画面理解，按需添加自己的人物或商品，然后选择生成单张、套图或宫格——现在就可以 **开始第一张作品**。

> 如果连接失败，不要反复重装扩展：先确认 Codex 已登录，再重新运行当前系统安装包里的连接组件，最后回到设置点击“重新检查连接”。

## 设计理念

- **参考优先**：先守住原图可观察的构图、光影、动作、材质和气质，再谈变化。
- **职责清楚**：参考图决定怎么拍；人物／商品素材决定拍谁或拍什么。
- **用户做最终决定**：质量检查只给建议，不静默删除候选，也不暗中自动重生。
- **把复杂留给系统**：普通流程只有清楚的下一步，高级调整按需展开。
- **本地优先、可追溯**：没有 VisualForge 云端账号；作品关系、候选和最终选择都能回看。

## 它如何工作

```text
网页图片／上传参考图
          ↓
Chrome 侧边栏：捕获、理解、选择主体、管理作品
          ↓ Native Messaging
VisualForge 本地连接组件
          ↓ 本机 Codex App Server
视觉理解与 imagegen 图像生成
```

VisualForge 不复制 Codex 凭据，不要求 API Key，也不建立自己的图片生成服务器。只有你主动分析或生成时，所选图片和创作要求才会交给当前登录的 Codex／OpenAI 服务处理。

## 从源码构建

需要 Node.js 22+、pnpm 10+、Chrome 116+，以及已经安装并登录的 Codex。

```bash
git clone https://github.com/dososo/visualforge.git
cd visualforge
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
```

构建后的扩展位于 `apps/extension/.output/chrome-mv3/`。开发环境安装连接组件可运行 `pnpm setup:host`。仓库采用 pnpm workspace：扩展位于 `apps/extension/`，Native Host 位于 `apps/native-host/`，共享契约和创作逻辑位于 `packages/`。

## 隐私与边界

- VisualForge 没有中心服务器、账号、广告和遥测。
- Chrome Web Store 尚未发布；0.5.8 通过 Releases 提供透明的旁加载安装包。
- 只有主动分析／生成时，选中图片和要求才会发送给当前登录的 Codex／OpenAI 服务。
- 请只使用你有权处理的参考图和主体素材；不要用来冒充他人或生成未经同意的敏感内容。
- macOS 0.5.8 Universal 包经 Developer ID 签名、Apple 公证并 Staple；Windows／Linux 的签名和真机验收边界写在 Release 中。
